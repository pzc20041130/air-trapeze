# 空中飞人 · 上头观察室

一款自娱自乐的**黑色喜剧外汇模拟游戏**。你扮演一个不肯离场的赌狗，在模拟行情、真实历史汇率和 14 份金融危机档案里反复上头。

这里不生产财富，只记录你是怎么上头的。

## 启动

双击 `start.cmd`，或在项目目录执行：

```bash
node server.js
```

打开 <http://127.0.0.1:8130/>。

> 不要直接双击 `index.html`：`file://` 会限制浏览器存档和历史汇率请求。用本地服务器才完整。

## 桌面快捷方式

桌面上已经放了一个 **空中飞人** 快捷方式，双击会通过 `cmd.exe` 运行 `start.cmd`：

- 如果 8130 端口已经在跑，直接打开独立应用窗口；
- 如果没跑，启动本地服务器，等端口就绪后再打开独立应用窗口；
- 应用窗口使用 Chrome / Edge 的 `--app` 模式，没有地址栏、标签页和浏览器工具栏；
- 启动器控制台窗口最小化，不会抢焦点。

如果系统里没有 Chrome / Edge，会退回到默认浏览器打开 <http://127.0.0.1:8130/>。

图标与 PWA：

- `assets/icon.svg`：矢量源文件
- `assets/icon.png`：256×256 PNG
- `assets/icon-512.png`：512×512 PNG
- `assets/icon.ico`：Windows 多尺寸图标（16–256）
- `manifest.json`：应用名称、图标和独立窗口配置
- `AirTrapeze.exe`：旧版启动器文件，快捷方式已不再依赖它

如果移动了项目目录，快捷方式需要重建；图标本身不会丢。

## 新手流程

第一次进入：

1. 欢迎页点「先学怎么输」；
2. 5 步教程：先搞懂怎么赚钱，再看方向、保证金/杠杆、60%/80% 风险、收手；
3. **免费练习一笔**：保证金 $100、杠杆 10×，不算合同；
4. 平仓后，练习成绩清空，回到 $10,000，再选合同或自由模式。

练习期间，下单面板会出现一条“第一次试水”提示，告诉你每一步做什么。进阶交易在新手模式默认关闭；困难模式会自动开启。

手机端底部常驻交易条：可用余额、当前持仓浮盈、做多、做空，不用滚回下单区。

![新手练习](screenshots/onboarding-practice.png)

## 新手模式（教练模式）

默认进入新手模式。只保留一个决定：

> 你觉得会涨，还是会跌？

- 固定押 $100、5×；
- 自动止损：最多亏约 $20；
- 自动止盈：赚约 $40 落袋；
- 不显示保证金、杠杆、名义仓位、手续费、借款、持仓表；
- 房租/还债/裁员的目标降为 $100 / $7,200 权益 / $200；
- 合同开始后新手模式锁定，不能中途切回完整界面换工具；
- 教练结算只显示合同、结局和最终权益，不显示峰值、回撤和评级。

新手模式不改变市场规则，只是把第一次游玩的认知负担降下来。

## 难度模式

设置里可以切换：

| 模式 | 下单 | 环境 / 商店 | 合同目标 |
|---|---|---|---|
| 新手模式 | 只看涨/跌，固定 $100 / 5× | 跳过 | $100 / $7,200 / $200 |
| 困难模式 | 完整保证金、杠杆、进阶交易 | 完整 | $800 / $8,000 / $3,000 |

合同进行中不能切换难度；收手或结束后再回设置里改。

困难模式默认开启进阶交易，隐藏新手小抄和“第一次试水”提示，合同行使用：

```text
合同盈亏 / 目标缺口 / 成交 / 有效成交
```

新闻判断按钮使用 `利多 / 利空`。

## 市场环境（困难模式）

签合同后，困难模式会先选一个市场环境：

| 环境 | 影响 | 额外规则 |
|---|---|---|
| 平静周 | 新闻少、波动 ×0.8、合同目标 -15% | 评级上限 A |
| 央行周 | 重大事件更多、波动 ×1.25、合同目标 +15% | 完成合同后评级 +1 档 |
| 传闻周 | 整活/传闻更多、波动 ×1.05、目标不变 | 第一件商店商品半价 |

环境会影响新闻频率、行情波动和合同目标；新手模式跳过这一层。

## 三幕合同

每份合同拆成三幕，生活事件在每幕结束时触发：

| 合同 | 第一幕结束 | 第二幕结束 | 第三幕结束 |
|---|---:|---:|---:|
| 这个月房租 | 2 笔 | 4 笔 | 5 笔 |
| 还清肥鱼信贷 | 4 笔 | 7 笔 | 10 笔 |
| 被裁员的第 30 天 | 3 笔 | 6 笔 | 8 笔 |

- 合同行会显示 `第一幕 / 第二幕 / 第三幕`；
- 事件弹窗显示当前幕；
- 只有投入达到开局权益 1% 的交易，才计入幕进度；$10 微型交易不能刷幕；
- 合同行会显示 `有效 1/2`，低于门槛的交易会提示；
- 事件带来的生活费不计入合同进度；弹窗和选择后都会提示；
- 裁员合同最后两件事都在第三幕收束，会连续出现；
- 第二幕、第三幕开始前会进入幕间策略商店。

## 紧急事件

重大事件触发时，如果场上还有持仓，会直接弹出居中的 **EMERGENCY**：

- 10 秒倒计时；
- 市场继续走，不暂停；
- 时间到默认「硬扛」；
- 每份合同最多触发 2 次。

可选动作：

- 平仓避险；
- 使用对冲卡，平掉一半仓位；
- 使用追加保证金卡，或防守策略，从现金补 $100；
- 逆势策略解锁「逆势反手」；
- 硬扛。

![紧急事件](screenshots/emergency.png)

## 交易台与策略商店

困难模式签下合同后，先从 3 张起始策略里选 1 张。交易台最多 3 张策略卡。

四类流派，每类 2 张：

| 流派 | 示例效果 |
|---|---|
| 趋势 | 顺势交易手续费降低；2 张再额外降低 |
| 消息 | 新闻判断正确额外获得新闻积分；2 张再 +1 |
| 逆势 | 紧急事件解锁反手；2 张反手保留更多保证金 |
| 防守 | 止损返还 15%；2 张再返还 10% |

每张策略卡都带彩色流派标签：趋势、消息、逆势、防守。

每幕事件结束后进入策略商店：

- 随机刷 3 张策略；
- 买一张进交易台；
- 刷新一次 $100；
- 每幕只能买一张；
- 新闻积分每点让策略卡便宜 $50，最多 -$300；
- 买卡直接扣现金，和保证金共用一笔钱；
- 商店右上角的「图鉴」可以查看全部 8 张策略、费用和效果。

开局自带 1 张对冲卡；策略卡进交易台后会显示在“应急卡/交易台”区域，并在紧急事件里提供额外动作。

## 本局流派与评级

结算时会根据这局的行为给出最多 3 个流派标签：

| 标签 | 条件 |
|---|---|
| 消息猎手 | 两次在重大事件里开仓 |
| 止损机器 | 两次让系统替你止损 |
| 满仓赌徒 | 单笔押上半个账户 |
| 扛单王 | 有一笔扛了 10 根 K 线 |
| 铁公鸡 | 进过商店但一分钱没花 |
| 房租战士 | 两笔以上只用最小仓位 |
| 最后一把 | 按过「最后一次」 |

本局流派是行为标签，交易台是策略构筑，两者分开：

- 消息猎手：新闻积分获取更快；
- 止损机器：更常触发止损，配合防守策略；
- 铁公鸡：跳过策略商店返还 $20。

所以流派不只是结算标签，也会影响局内经济。

评级同时看合同完成度、交易笔数和回撤：

- **S**：完成合同，交易数 ≤ 60%，回撤 ≤ 12%
- **A**：完成合同，交易数 ≤ 80%，回撤 ≤ 25%
- **B / C**：未完成，但权益没有穿仓
- **D**：破产

流派只在困难模式结算，新手模式保持简单。

## 怎么赚钱（大白话）

- **做多**：价格涨才赚。平仓价高于开仓价，才有得赚。
- **做空**：价格跌才赚。平仓价低于开仓价，才有得赚。

例子：

```text
做多：1.1000 买入，涨到 1.1010 平仓 → 赚
做多：1.1000 买入，跌到 1.0990 平仓 → 亏

做空：1.1000 卖出，跌到 1.0990 平仓 → 赚
做空：1.1000 卖出，涨到 1.1010 平仓 → 亏
```

开仓后可用余额变少，通常是**保证金被锁住**，不是钱没了；平仓后会回来。真正变化的是**账户总权益**和**浮动盈亏**。

## 收手 / 穿仓结案

- 余额旁的「收手离场」会按当前价格结算所有持仓，结束本局，弹出结算：最终权益、本局峰值、最大回撤、待还贷款、“最后一次”次数、诊断。
- 结算后交易冻结，按钮变成「再来一局」；点它才真正清空当前模式重开。
- 结算弹窗里可以直接点「查看病历库」，不用再绕顶栏。

- 每局结算会存进 localStorage 的 `af-cases-v1`，并出现在病历库里。
- 每日挑战「金盆洗手」也会留一份挑战结算记录。

## 合同结局

每个合同有 3–4 个结局，由“是否完成目标 / 债务 / 关键事件选择”决定：

- **房租**：交上房租 / 下个月再说 / 账单替你记住 / 换个城市
- **还债**：上岸 / 家人兜底 / 轻装上阵 / 跑路
- **裁员**：重新入职 / 灵活就业 / 先干着 / 换个城市
- **通用**：自由落体（穿仓）；**空中飞人**（负债达到当前空中飞人线）

**空中飞人线**不是固定 $5,000：

```
$5,000 + 交易数 × $250 + 正收益 × 50%
```

四舍五入到 $100。玩得越久、赚得越多，要触发“空中飞人”所需的负债门槛越高。

事件选择会记录 flag，例如“告诉家人”“准备面试”“给房东转钱”，结局会读这些 flag。

![空中飞人结局](screenshots/ending-airborne.png)

病历库会记录事件时间线，例如：

> HR 约谈 → 签协商离职（+$1,500）  
> 三天后有个面试 → 停手准备（-$100）

## 黑色喜剧层

- **旁白**：开仓、爆仓、借钱、拒绝补仓、收手都会触发毒舌旁白。
- **新闻条**：连续滚动，最多显示最近 5 条；没有新闻时显示 3 条新手提示，不再是一动不动的“等待下一个借口”。
- **实时事件**：最多 3 个事件同时生效，每个事件有 16–27 根 K 线的持续时间；事件卡只给标题、正文、梗和剩余根数，不标注受影响货币对和方向，需要玩家自己推断。
- **突发新闻**：重大事件会出现红色警报条，显示剩余秒数和「立即判断」；9–12 根 K 线的短窗口、2.7–3.0× 波动，直接命中当前货币对。
- **相关与蝴蝶**：两国之间的贸易、制裁、疫情、航运事件会直接偏置相关货币；分析师、芯片、供应链等市场梗不直接给方向，只通过全市场波动产生蝴蝶效应。
- **整活新闻**：咖啡机、体检报告、外卖备注、房东、相亲、猫踩键盘、券商 PPT、塔罗牌非农等纯娱乐新闻，只进滚动条、新闻浮窗和新闻中心，不占用事件卡，也不改变行情；这类新闻和 meme 事件不显示分类标签。
- **段子事件**：50+ 条新闻模板，覆盖专家建议、财经大V、房东、交易所咖啡机、体检报告、外卖备注，以及海峡封锁、贸易战、疫情变种、港口拥堵、芯片缺货、制裁、停火传闻等国际局势事件；部分事件有后续链，比如“专家建议 → 专家关评论 → 专家删号”“新关税 → 反制清单 → 谈判重启”。
- **下单回执**：开仓后右侧立即出现当前持仓卡，显示方向、浮盈、开仓价和距爆仓百分比；可用余额和已用保证金会闪一下。
- **余额常驻**：下单区常驻显示可用余额和已用保证金，不用再往上看账户卡。
- **最后一次**：标准模式下，亏损平仓后主按钮是「最后一把，回本就走」，旁边是「算了，收手」。每按一次计数 +1，第 10 次确诊「最后一次」。安全网下不会出现这个按钮。
- **现在收手**：余额区显示当前可带走金额、本局峰值和回撤；旁边的「收手离场」会真正结算并结束本局。
- **风险线**：持仓后图表会画出开仓线、爆仓线，持仓行显示「现价距爆仓百分比」。
- **部分平仓**：持仓行可以平掉 25% / 50% / 75%，风险弹窗可以平掉一半；平仓后保证金和名义仓位按比例减少，剩余仓位继续跑。注意：平掉一半只锁定一半盈亏，剩余仓位的风险比例不会自动下降。
- **止损 / 止盈**：设置 →「进阶交易」打开后，下单时可填止损价和止盈价。只开仓时设置，开仓后不能改；触发按当前价成交，跳空可能更差；止损/止盈触发后不会出现「最后一把」。
- **肥鱼信贷**：随借随到，利息按天算，尊严按次算。图标直接用“大肥鱼”——原创鲸鱼娘，深海蓝发、鲸鱼尾发饰、鳍耳、制服和金币。
- **事故报告**：1080×1440 分享卡，带红色「建议休市」印章、诊断、峰值、回撤和“最后一次”次数。
- **病历本**：13 个成就全部改成确诊记录。

## 止损 / 止盈

设置 →「进阶交易」打开后，下单面板多出两个可选价格：

- **止损价**：价格到点自动认亏平仓；
- **止盈价**：价格到点自动落袋。

规则：

- 默认关闭，不影响新手界面；
- 只开仓时设置，开仓后不能改；
- 多单止损低于现价、止盈高于现价；空单反过来；
- 止损必须比爆仓价更早触发，否则会先爆仓；
- 触发按当前价成交，跳空时可能比设置价更差；
- 触发后不出现「最后一把」；
- 持仓行只在设置了的时候多一行小字：`止损 x · 止盈 y`。

## 交易规则

- 7 个货币对；标准模式 1–100 倍杠杆，安全网最高 20 倍。
- 开仓手续费 = 名义仓位 × (0.00005 + 杠杆 × 0.000005)。
- 浮亏达到保证金 60% 触发风险提醒，80% 强制平仓；跳空可能穿仓。
- 部分平仓没有额外手续费，按比例释放保证金并结算对应盈亏。
- 止损/止盈触发没有额外手续费，按当前价结算；跳空可能滑点。
- 贷款上限 $200,000，日利率 0.01%–0.04%。
- 四种模式独立账户，进度保存在 localStorage。
